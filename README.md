# SYNTHESIS — Complete Regional Painting Fusion Studio

This is the integrated, full-experience version of the Regional Painting Fusion Project.

## Assignment objective

Create an artwork that combines elements from two or more regional painting styles, exploring similarities and differences and producing a creative synthesis.

## Product

SYNTHESIS combines the complete learning/creation/exhibition workflow in one application:

1. Curator's Routes — guided thematic discovery.
2. Regional Atlas — interactive geographic context.
3. Tradition selection — eight documented visual traditions.
4. Concept selection — community, nature, ritual, memory, movement, identity, celebration, migration, environment, contemporary India.
5. Composition selection — central icon, circular narrative, horizontal story, shrine, diagonal movement, dense pattern, landscape, procession.
6. Live Creative Atelier — editable artwork canvas.
7. Visual Vocabulary — tradition-specific motifs that can be added to the canvas.
8. Object Inspector — move, rotate, opacity, duplicate, lock, delete.
9. Curatorial Analysis — live synthesis diagnostics and cultural-practice guidance.
10. Chrono-spatial timeline — 12,000 BCE through contemporary practice.
11. Material Lab — earth, rice/light grounds, mordant/dye, gold, cloth, wood, paper/canvas.
12. Artist Statement — editable academic documentation.
13. Academic Rubric — explicit grading criteria.
14. Curator Certification — eight reasoning-based questions.
15. Exhibition Dossier — print-ready final submission.

## Important cultural/academic framing

The artwork builder is an original digital study. It should not be described as an authentic example of a traditional community practice.

The application distinguishes:
- source tradition
- visual principle
- student transformation
- curatorial interpretation

The dataset intentionally avoids claiming that all regional traditions are interchangeable.
